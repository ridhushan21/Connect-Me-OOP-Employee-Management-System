# 🔗 Connect Me – OOP Employee Management System

Connect Me is a Java-based Object-Oriented Programming (OOP) application designed to streamline employee management within an organization. The system enables efficient handling of employees, departments, and user roles through a structured and scalable architecture.

## 🚀 Features

* 🔐 User Authentication (HR Manager & HR Assistant)
* 👥 Employee Management (Add, Update, Delete, Search)
* 🏢 Department & Designation Management
* 🔎 Advanced Employee Search Functionality
* 👤 Role-Based Access Control
* 📊 Interactive Dashboards (Manager & Assistant)
* 💾 Data Storage & Retrieval System

## 💡 Project Overview

The Connect Me system automates traditional employee management processes by providing a centralized digital solution. It allows HR Managers to manage employees, departments, and roles, while HR Assistants can efficiently search and retrieve employee information.

The system is built using core Object-Oriented Programming principles to ensure scalability, maintainability, and security. 

## 🧠 OOP Concepts Applied

* 🔒 **Encapsulation** – Secure handling of employee and system data using private attributes
* 🧩 **Abstraction** – Simplified system design using abstract classes and methods
* 🧬 **Inheritance** – Role-based class hierarchy (HR Manager & HR Assistant extend User)
* 🔄 **Polymorphism** – Flexible methods for searching and managing employees
